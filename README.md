# 刘海小球交互原型 0.37

## 更新

### 0.37 · 更轻盈的日常操作

- 小球增加模块图标；控件扩大点击区域，统一悬停、按压反馈和中文辅助说明。
- 番茄钟采用目标/计时卡片、明确的主按钮和独立环境声区域；保留连续专注与记录逻辑。
- 音乐窄布局自动精简，展开后给歌词更多空间；提醒事项和便笺统一标题与输入区。
- 动画可随操作即时打断；在拖动控件时继续平滑运行。减少动态效果时关闭主要位移动画，固定穿透时停止光晕连续刷新。
- 输入时移开鼠标不会收起面板；Esc 退出编辑并收起，固定模块和正在进行的专注会保留。
- 专注统计改为卡片层级，修复热力图图例色阶与月份标题挤在一起的问题。

这是使用 Sparkle 签名的未公证测试版。已安装版本可通过菜单“检查更新”升级。
开发者可以运行 `python3 scripts/preview-ui.py` 渲染真实组件的虚构数据预览；产物在忽略目录 `build/ui-previews/`。

### 既有功能

菜单栏“检查更新”使用 Sparkle 2.10.0，从仓库 `main/appcast.xml` 获取更新。
发布工具、测试版与正式版的区别、故障恢复步骤见 [自动更新发布流程](RELEASE.md)。
`./build.sh` 默认只做本地临时签名；正式发布必须使用 Developer ID 签名并通过 Apple 公证。
不要将未公证测试版称为正式公开版。私钥始终留在本机钥匙串。

本版为番茄钟展开界面增加“结束并记录”按钮；紧凑胶囊运行中的停止按钮也执行同一操作。结束后解除番茄钟的自动 Pin，并将本次主题的实际专注时长保存为一条记录。例如 `CMC problem`：25 + 25 + 10 分钟，保存为一条 60 分钟记录，休息时间不计入。

“最近专注”按一次命名主题会话记录：多轮专注合并为一个条目，只累计专注时间，不把短／长休息算入。主动结束或退出 App 时，即使未满 25 分钟也保存，进行中会话同时在统计里显示。今日热力图与时长包含部分专注；今日次数按主题计算。旧版已经保存的逐轮历史不推测合并，以免把同名的不同主题误合并。

长休息开始时，在番茄钟胶囊下方显示喝水（5 秒）和站立（10 秒）提示。圆环倒计时归零后，图标向上收回胶囊；提示排布由数量、直径和间隔计算，支持以后扩展为三个或更多图标。提示只负责展示，不拦截鼠标、不影响长休息倒计时或统计。提前跳过／结束会话会清除提示，减少动态效果开启时采用淡入淡出。

番茄钟持续循环：专注 → 短休息 → 专注 → 长休息 → 专注，默认每完成两轮专注安排长休息。阶段到点自动开始下一阶段并播放提示音，直到主动“结束番茄钟”。只在会话开始命名，后续轮次沿用名称，每个完成的专注轮次独立记入统计。暂停不结束会话，恢复继续；手动跳过阶段保持原运行／暂停状态。已安装旧版的设置迁移到连续循环、每两轮长休息，保留原时长及环境声配置。

Pin 支持音乐、番茄钟、提醒事项与便笺，并保存各模块的锁定状态。离开后保留当前锁定模块；当前模块未锁定时回到最近锁定的模块。开始专注自动锁定番茄钟，可手动取消锁定而不停止计时。番茄钟紧凑胶囊显示阶段、专注名称、倒计时、进度环、运行／暂停状态，以及暂停、Pin、展开控件。

专注完成进入休息时播放 Glass 系统音效；休息结束进入专注时播放 Ping 系统音效。手动跳过阶段也播放对应提示，暂停／恢复不重复播放。系统音量／静音影响提示音；环境声的音量不影响提示音。结束会话后，开始新的会话需要重新命名。

边缘改成 Siri 风格的连续柔和彩色光晕：蓝紫、粉色、暖橙色通过动态网格渐变相互融合，颜色区域缓慢变形，配合轻微明暗呼吸与白色玻璃高光。光晕限制在边缘，不盖住胶囊内容。穿透时更轻，可点击时稍亮；系统“减少动态效果”开启时保持静态。

动态内容与玻璃背景分开：穿透状态原生 clear 玻璃背景的不透明度上限为 22%，不随歌词更新提高遮挡；文字与控件保持完整不透明度，采用浅色文字及轻微阴影，边缘保留高光。可点击状态恢复完整 regular 磨砂材质。仅对锁定常驻胶囊启用这种区别。保留音乐歌词、番茄钟、提醒事项及便笺功能。

玻璃背景使用系统原生折射效果，并在切换全屏／桌面后重新挂载；系统折射与底色会随背景调整，但穿透时的背景层始终受 22% 不透明度限制。已验证原生背景层在 clear → regular → clear 及尺寸更新后的配置；实际跨应用全屏观感尚需确认。

## 全屏避让与位置

默认位置为刘海下方，全屏也保持这一位置。位置偏好本版重置为默认。菜单栏 `● → 位置` 仍可选择其他位置。

Pin 音乐或运行中番茄钟常驻显示；闲置状态下，整个胶囊允许鼠标点击穿透到下面的应用，并显示透明玻璃。操作胶囊时，先把鼠标移到屏幕顶部的刘海区域停留约 0.25 秒，再移到胶囊。离开控件后，按原收起延迟恢复穿透。菜单栏打开模块也会启用控件。只有实际球体和胶囊轮廓接收点击，透明空白及球体周围不拦截鼠标。拖动滑块时保持捕获。主动操作期间，胶囊覆盖的应用按钮仍需先移开鼠标、等待恢复穿透后点击。

已验证全屏／普通最大化窗口的几何判定、小屏幕及负坐标显示器布局、各模块展开高度，以及真实 AppKit 小球／胶囊视图的鼠标命中范围；未逐一实测所有第三方应用的全屏模式。

## 番茄钟与环境声

1. 双击 `Notch Balls Prototype.app`，将鼠标移到内置屏幕刘海正下方，点击番茄钟小球。小球会在同一行变成胶囊，向下箭头展开控制面板。
2. 在“这次专注要做什么？”中输入名称，再点“开始”或按回车。未命名时不会开始专注。暂停后继续沿用本轮名称；重置或开始下一轮专注时需重新命名。
3. 运行期间，鼠标移开后展开面板收回，但计时胶囊常驻。临时打开其他模块后，关闭模块或将鼠标移开，会回到计时胶囊。点“结束番茄钟”或菜单栏同名命令才会取消常驻。
4. 在“环境声混音”中点“播放”开启所有音量大于零的声道；再次点击可关闭。底噪可选“柔和”“深沉”或“关闭”，可与雨声、海浪和溪流同时播放。每条音量轨都能独立拖动，拖到零相当于静音。混音选择和音量会保存在本机。
5. 默认专注 25 分钟、短休息 5 分钟，每完成 4 次专注后长休息 15 分钟。跳过的专注不会计入统计。系统提示音在阶段结束时响起。
6. 菜单栏 `● → 番茄钟默认设置` 可调整时长、长休息间隔、默认底噪以及是否在专注时自动播放环境声。新时长不会改动正在运行的倒计时。自动开始只适用于休息阶段，下一轮专注仍会等待命名。

## 专注统计

从菜单栏 `● → 打开专注统计` 打开独立窗口。窗口展示今日与累计专注次数、时长、过去一年按天着色的热力图，以及最近的命名专注。正在进行的专注会立即显示在“最近专注”中，包括已专注的分钟数；只有完整完成的专注才会计入次数、时长、热力图和永久记录。将鼠标停在方格上可查看当天次数和分钟数。旧版累计数据继续显示在热力图中，旧记录没有名称。

设置、统计和命名记录保存在本机应用偏好中。退出应用会停止当前倒计时；已完成的专注记录仍在。

## 提醒事项与小球配置

“提醒事项”胶囊中的“查看”可展开列表。点击标题查看备注和到期时间，点击空心圆完成事项。底部输入新事项，可勾选“到期时间”设置日期与具体时间，并决定是否在到期时提醒；按回车或点加号保存。首次使用需允许系统提醒事项权限。新事项写入系统默认列表；若该列表通过 iCloud 同步，系统会同步变更。

“便笺”连接系统 Apple 备忘录：展开后读取默认账户中的前八条，点击标题在备忘录中打开，底部可快速新建一条。第一次操作时，macOS 会询问是否允许此应用控制“备忘录”。若拒绝，可在“系统设置 → 隐私与安全性 → 自动化”中重新允许。

点音乐小球后会先出现一条横向长胶囊：封面、曲名、当前歌词、上一首、播放/暂停、下一首和 Pin 都在同一行。点曲名、歌词或展开图标，胶囊横向变宽，左边是封面，右边是歌曲信息、控制、进度和歌词。Pin 只控制常驻，不切换布局；固定后鼠标移开仍保持当前状态，关闭或取消 Pin 后恢复自动收起。若番茄钟同时运行，音乐 Pin 优先占用刘海胶囊，番茄钟仍在菜单栏继续计时。

### 歌词来源与匹配

展开音乐胶囊后，底部“歌词来源”菜单提供：

- **自动回退**：已开启联网歌词查询时，优先读取已开启的网易云当前歌曲歌词；没有歌词再查已开启的 QQ、酷狗、LRCLIB，仍无匹配才自动查询 [VV 歌词库](https://vvlyrics.com/)。不需要另开 VV 开关。关闭联网查询会同时停止后续回退查询。VV 只发送歌名、歌手；按页面结构化元数据及歌词标题、歌手标签校验，支持简繁体匹配。菜单显示“已自动回退至 VV 歌词”；未标注版本时长时注明“时长未标注”。
- **开启多源**：将当前曲名、歌手与时长用于查询 QQ 歌词、酷狗歌词和 LRCLIB。只获取歌词，不获取音频、不切换播放器，不需要登录这些平台。菜单明确标注发送的信息；旧版 LRCLIB 开关不会自动开启额外平台。
- **网易云歌词**：保持原有独立开关。只读匹配本机网易云歌曲缓存，将歌曲 ID 发给网易云歌词接口。与多源结果一起提供候选。
- **扩大检索**：曲名与歌手精确查询没有可信结果时，自动只按歌名重试已开启的 QQ、酷狗和 LRCLIB，按专辑、时长排序并去重。歌手名未确认的相近结果显示“待确认”，不会自动播放错误版本的歌词。时间或专辑信息不足的陌生歌手候选会过滤；拼音只能辅助排名，不会仅凭拼音确认身份。
- **确认候选并记住**：在“歌词来源”中点“确认匹配”保存本曲选择。候选为单一歌手时，同时保存播放器歌手名与候选歌手名的本地对应；下次同一歌手可直接用已确认名字搜索。合唱候选只保存歌曲选择。仍可从“校正歌词匹配歌手名”修改或恢复对应关系。
- **标题与艺名处理**：统一简繁体、大小写和宽度，识别括号内艺名和合唱分隔符；搜索时清理 Remastered／重制标注，仍保留 Live 等版本差别。内置 `Lo Ta-You / 羅大佑 / 罗大佑` 对应关系继续生效，播放器显示名保持原样。
- **可选的艺名联网识别**：在“歌词来源 → 开启艺名识别”中授权，只将歌手名发送到 [MusicBrainz](https://musicbrainz.org/doc/MusicBrainz_API) 查询公开名字及别名，不发送歌名、播放进度或账号。默认关闭；确认身份唯一时才用其他语言名称重试已有歌词源。同名歧义不自动选择。结果缓存本机，查询间隔至少 1.1 秒，失败时继续普通搜索。关闭联网查询会关闭后续艺名联网识别。已用与当前播放无关的公开示例验证 API 搜索及别名数据；没有向 MusicBrainz 发送用户当前播放信息。
- **候选版本**：比较曲名、歌手、专辑和时长，过滤明显不符的 Live 与长度不同的版本；未知歌手的相近候选须人工确认，可信结果优先显示。菜单列出来源、专辑和时长，手动选择会按歌曲保存。
- **同步偏移**：提前或延后 0.5 秒，可恢复原始时间。正值提前、负值延后，范围 ±30 秒，按歌曲保存；播放进度不会改变。支持 LRC 多重时间标签和文件内 offset 标签。
- **导入本地 LRC / TXT**：选择不超过 1 MB 的 UTF-8 文件，为当前歌曲保存本地歌词；无需联网。带时间标签时跟随播放，TXT 显示静态文本。本地导入优先于自动匹配。
- **重新查询 / 关闭联网查询**：可重试失败的来源或停止后续联网查询。部分来源失败时，其余来源结果仍可用。切歌后，旧歌的查询结果不会覆盖新歌。

本机偏好保存来源开关、手动版本、偏移和导入的歌词。来源数量不保证每首歌都能查到；接口不可用和未匹配到歌词会区分提示。VV 页面结构及 QQ、酷狗和网易云接口不是稳定公开 API，升级或服务调整后可能需要适配。Musixmatch、LyricFind 尚未接入；AMLL 社区 TTML 库也尚未接入，不显示为可用来源。

QQ、酷狗的接口参数参考 [LyricsKit 的公开实现](https://github.com/ddddxxx/LyricsKit)，本版查询和匹配逻辑单独实现。已按 Apple Music 实际返回的 `新生代 / Lo Ta-You / 首都 / 281.447 秒` 信息验证自动回退可返回 28 条逐句歌词；也已用预设公开示例验证 QQ、酷狗和 LRCLIB 同步歌词；开发测试仅查询预设歌曲及用户明确指定的歌名、歌手，没有读取播放账号或发送账号数据。网易云当前账号歌词仍未做联网实测。

退出应用后编辑与 `.app` 同目录的 `scene.json`，再重新打开应用，可调整模块、小球大小、间距与动画。旧配置中的 `timer` 模块会自动变成“番茄钟”。菜单栏 `● → 退出原型` 可完全退出应用。若 macOS 首次阻止打开，请在 Finder 中右键应用并选择“打开”。

## 从源码构建

需 macOS 14 或更新版本以及 Xcode Command Line Tools。运行 `build.sh` 会重新生成两种底噪，并编译 Swift 源码、拷贝 `now-playing.jxa`、临时签名应用。`audio/*.wav` 是已处理好的自然录音，构建时直接拷贝进应用。
